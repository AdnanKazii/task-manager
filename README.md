# Task Manager
A simple task manager built with Angular using standalone components and SQLite for storing tasks. This app allows users to add, mark as complete, and delete tasks.

# Technologies Used
Frontend: Angular (standalone components), HTML, CSS
Backend: Node.js, SQLite (if using a backend for persistence)
Forms: Angular's ngModel for two-way data binding

# Prerequisites
Node.js and npm: Ensure you have Node.js and npm installed on your system.
Angular CLI: Install Angular CLI globally with the following command:
npm install -g @angular/cli

# Installation Steps
Clone the repository (or create the project manually)
git clone <repository-url>
cd task-manager-frontend

Install dependencies
Run the following command to install the necessary packages for the Angular project:
npm install

Start the Angular Development Server
Run the following command to start the Angular app:
ng serve

This will start the development server at http://localhost:4200/. You can open this URL in your browser to view the app.

# Usage
Add Tasks: Enter a task name in the input field and click the "Add" button to add a new task to the list.
Toggle Completion: Use the checkbox to mark tasks as completed or pending.
Delete Tasks: Click the "Delete" button next to any task to remove it from the list.
